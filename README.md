# Bipem image replacements

Add your own images to the website root, alongside `index.html`, using these filenames. Configured local images are checked first and use the online placeholder photo if missing or unable to load. Team entries without a configured verified portrait show initials instead.

Use landscape crops for site and project photos, and portrait crops for team headshots. WebP is recommended; update the matching filename in `index.html` when using JPG.

`bipem-logo.png` in the website root is the transparent company logo used in the header and loading screen; preserve its transparent background when replacing it.

No Gladys or Samuel Mureithi Kioni headshots were present in the Sirius Energy project folder. Their team cards currently show initials until verified portraits are available.
To add their portraits later, add the files below and configure their image keys in the team data and `IMAGES` map in `index.html`.

- `hero-site.webp` — engineering fieldwork, borehole drilling, or survey in progress
- `field-team.webp` — Bipem team working at a project site
- `water-engineering.webp` — water infrastructure, borehole, or water resource project
- `gis-mapping.webp` — GIS workstation, mapping, or remote-sensing work
- `industrial-lifting.webp` — industrial lifting, forklift, or material handling
- `project-samburu-borehole.webp` — Samburu borehole and water-pan project
- `project-shidley-water-supply.webp` — Shidley water-supply infrastructure
- `project-kaasuvi-solar-flood-study.webp` — Kaasuvi solar plant or flood-study project
- `team-peter-muiruri.webp` — Peter Muiruri headshot
- `team-samuel-kioni.webp` — Samuel Mureithi Kioni headshot
- `team-gladys.webp` — Gladys headshot
